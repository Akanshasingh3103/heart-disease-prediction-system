How it works

Answer in four short steps

Profile, chest symptoms, vitals and blood, then heart tests. Every question explains what it means and what a typical value looks like.

Watch the meter move

A logistic regression model trained on the dataset updates after every answer, right in your browser. Nothing you enter leaves this page.

See what drove the result

The results page ranks every answer by how much it pushed the estimate up or down compared with an average patient.

About the model and the data
  • Source: the 14-column heart disease table you provided (age, sex, chest pain type, blood pressure, cholesterol, and so on).
  • The file holds 1,025 rows but only 302 distinct patients. Exact repeats were removed before training so that test scores are not inflated by the model seeing the same patient twice.
  • In this file, target = 1 marks patients without disease (164 of 302, matching the original clinical study). HeartGuardAI reverses it, so the percentage always means likelihood of disease.
  • Several category codes are numbered differently from the common online description. Labels here follow the counts in your data, for example chest pain code 0 is "no symptoms" because it is the largest group, as in the original study.
  • Model: standardised numeric inputs, one-hot categories, L2-regularised logistic regression. A random forest scored the same (about 82% accuracy), so the simpler and explainable model was kept.

Not a diagnosis. HeartGuardAI is a learning project built on a small research dataset. It cannot replace an examination, an ECG or a conversation with a doctor. If you have chest pain, shortness of breath or fainting, seek medical care now.
